# Y2K Channel — Official Showcase Website

Welcome to the official GitHub repository for the **Y2K Channel** showcase website. 

Y2K Channel is a Tamil infotainment platform dedicated to exploring Sci-Tech, social awareness, unknown facts, current topics, real truths, and money/business-related topics in Tamil. Our motto is simple: **Learn What Others Miss.** 

This repository contains the ultra-lightweight, SEO-optimized, and mobile-friendly source code for the Y2K Channel website.

## 🌐 Live Website
[Visit the official Y2K Channel Website Here](https://y2kchannel.netlify.app/) 

## 🚀 Features
*   **Ultra-Lightweight:** Built with pure, vanilla HTML, CSS, and JavaScript. No heavy frameworks.
*   **Mobile-First & Touch Friendly:** Perfectly optimized for iOS, Android, and all touchscreen devices.
*   **SEO Optimized:** Includes JSON-LD structured data, Open Graph meta tags, and Google Search Console verification readiness.
*   **Content Protection:** Includes basic JavaScript and CSS to prevent casual text selection, image dragging, and copying.
*   **Direct Integration:** Quick-access buttons to visit and subscribe to the YouTube channel.

## 🛠️ Tech Stack
*   **HTML5** (Semantic structure)
*   **CSS3** (Custom styling, Flexbox, Responsive Design)
*   **Vanilla JavaScript** (DOM manipulation, anti-copy protection)

## 📂 How to Use / Setup
1. Clone this repository or download the files.
2. Ensure the `logo.jpg` file is in the same directory as the `index.html` file.
3. Open `index.html` in any web browser to view the site locally.
4. To host it for free, drag and drop the folder into [Netlify](https://www.netlify.com/) or use GitHub Pages.
